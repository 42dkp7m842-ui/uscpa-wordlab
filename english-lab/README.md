# ENGLISH LAB — TOEIC・ビジネス英語

GitHub Pages: https://42dkp7m842-ui.github.io/uscpa-wordlab/english-lab/

USCPA Word Lab の既存画面とは別の `english-lab/` フォルダに置いた、iPhone向けの英語暗記PWAです。

## はじめかた

1. Safariで上の URL を開きます。
2. ホーム画面の「単語6,500語とフレーズを読み込む」をタップします。初回はインターネット接続が必要です。
3. 画面に登録済み語数が表示されたら、学習→出題開始で確認します。
4. Safariの共有ボタン→「ホーム画面に追加」でアプリのように利用できます。

Safariとホーム画面アプリでブラウザ保存領域が分かれる場合があります。追加したアプリでもデータを初期登録するか、設定→JSONバックアップで引き継いでください。保存データはその端末のローカルストレージに保存され、端末間で自動同期されません。

## 収録内容と注意

- 目標: 6,500語（2,000 / 2,000 / 1,500 / 1,000）＋1,000フレーズ候補
- 読み込み前はスターター単語とフレーズのみ収録
- 読み込み時に公開語頻度データと英和辞書から語彙・訳語を自動選定します。**TOEIC公式の単語一覧ではなく、全件校正済みでもありません**
- フレーズの自動抽出分はビジネス英語としての有用性を保証しません
- 英日、日英、4択、リスニング読み上げ、簡易間隔反復、学習履歴、検索、お気に入り、CSV/JSON取り込み・JSONバックアップ
- サーバーアカウント不要、語彙と学習履歴は端末保存。ログイン・同期機能なし
